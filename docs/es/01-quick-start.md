# Guía de Inicio Rápido

Bienvenido a SentinelArg. En menos de 10 minutos tendrás la plataforma funcionando.

### Paso 1: Requisitos Previos
- **Windows:** Docker Desktop instalado y en ejecución.
- **Linux:** Docker Engine y Docker Compose V2 instalados.
- Mínimo 8 GB de RAM libres.

### Paso 2: Descarga y Extracción
Descarga el paquete `SentinelArg_Windows_v1.0.3.zip` o `sentinelarg-linux-v1.0.3.tar.gz` desde tu panel de cliente y extráelo.

### Paso 3: Instalación
**En Windows:**
1. Abre la carpeta extraída.
2. Haz clic derecho en `1_Instalar_SentinelArg.bat` y selecciona **"Ejecutar como administrador"**.
3. Sigue las instrucciones en pantalla (acepta instalar Ollama si tienes RAM suficiente).

**Video instalacion en Windows:** https://youtu.be/jyS0oi1HnD8

**Video instalacion en Linux:** https://youtu.be/47uMSZySgP8

**En Linux:**
```bash
cd sentinelarg-client-release
sudo chmod +x install.sh
sudo ./install.sh

Activación
Ejecuta el script de activación con tu clave:
Windows: .\2_Activar_Licencia.bat (como Administrador)
Linux: sudo ./activate.sh TU_CLAVE_DE_LICENCIA
Acceder al Dashboard
Abre tu navegador y ve a: http://127.0.0.1:8888/dashboard
